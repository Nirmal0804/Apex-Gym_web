APEX FITNESS - Project Rules

• Follow a premium, minimal, and modern design throughout the project.
• Maintain a consistent design system across all sections.
• Prioritize quality over quantity—every element must have a purpose.
• Keep the UI clean with generous whitespace and proper visual hierarchy.
• Use minimal text; let visuals communicate the message.
• Always maintain consistency in spacing, typography, colors, border radius, and component styles.
• Build mobile-first and ensure seamless responsiveness on all screen sizes.
• Write clean, reusable, scalable, and production-ready code.
• Use semantic HTML and accessibility best practices.
• Implement smooth scrolling and subtle, meaningful animations only.
• Keep interactions smooth, polished, and performance-friendly.
• Avoid unnecessary sections, components, decorations, and animations.
• Do not redesign or modify previously completed sections unless explicitly instructed.
• Reuse existing components and patterns instead of creating new variations.
• Complete one section fully before moving to the next.
• Preserve visual consistency across the entire website.
• Always optimize for performance and fast loading.
• If multiple solutions exist, choose the simplest, cleanest, and most maintainable one.
• Do not make assumptions or add extra features without approval.
